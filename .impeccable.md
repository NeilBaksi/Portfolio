## Design Context

### Users
Recruiters, PMs, engineering managers, and potential collaborators discovering Neil through LinkedIn or direct link. Viewed on desktop primarily (portfolio is a first impression artifact, not a daily tool). Users are decision-makers assessing technical credibility + strategic thinking in under 2 minutes.

### Brand Personality
Sharp. Technical. Ambitious.

Neil bridges engineering and business strategy — the site should feel like it was built by someone who could lead a product team, not just ship tickets. Confident, not flashy. Dense with signal, not decoration.

### Aesthetic Direction
Dark theme (intentional — tech credibility, used by target audience in office/evening contexts). Teal accent (`#5eead4` / `#14b8a6`) as the sole accent color — used sparingly. Oxanium typeface — geometric, futuristic, non-default. Strong typographic hierarchy.

Anti-references: agency portfolio sites with heavy parallax and full-page scroll takeovers. Pastel/light "friendly designer" portfolios. Anything that looks like a Framer template.

### Design Principles
1. **Sparse accent use** — teal earns attention because it's rare. Don't dilute it.
2. **No banned patterns** — no gradient text, no side-stripe borders, no glassmorphism for decoration.
3. **Text hierarchy over visual noise** — let the typography do the work.
4. **Functional motion only** — the 3D character + loading marquee are the hero moments; everything else defers.
5. **Sharp spacing rhythm** — 4pt scale, tighter groupings, generous section gaps.

## Component Patterns & Tokens (execution contract — all agents follow verbatim)

### Tokens (from `src/index.css`)
- Font: `"Oxanium", sans-serif` (headings + body). No second family.
- `--accentColor: #5eead4` (teal, primary). Secondary teal `#14b8a6`.
- `--backgroundColor: #0a0e17`. Body text `#e6edf3` / `#eae5ec`.
- Muted text: `rgba(230, 237, 243, 0.65)`; borders: `rgba(230, 237, 243, 0.14)`; accent hairlines: `rgba(94, 234, 212, 0.12)`.
- Layout: `--cWidth`, `--cMaxWidth: 120rem`, `--vh`. Section vertical padding `80px 0`.

### Section wrapper pattern
```tsx
<section className="{name} {name}-section" id="{name}">
  <div className="{name}-container section-container">
    <header className="{name}__header">
      <h2 className="{name}__title">My <span>Label</span></h2>  {/* span → accent */}
    </header>
    {/* content */}
  </div>
</section>
```
- Section IDs kebab-case. Background `var(--backgroundColor)`, `z-index: 1`.
- Title `<span>` gets `var(--accentColor)`. Uppercase reserved for short labels only.

### Card pattern (Projects reuses Work's language exactly)
- Grid: `repeat(2, 1fr)`, `gap: 1px`, hairline bg `rgba(94,234,212,0.12)`; collapses to `1fr` at `900px`, stacks number above content at `480px`.
- Card: leading zero-padded `__num` (01, 02…), `__name` (1.5rem/600), `__category`/`__desc`, `react-icons` tech row `__stack` with per-icon `--icon-color`, optional `__tools` chip list.
- Hover only on linked cards: `background: rgba(94,234,212,0.04)`, `box-shadow: inset 0 0 0 1px var(--accentColor)`, name → accent. Transition `180ms ease`.
- WIP badge: small uppercase label, hairline border `rgba(230,237,243,0.14)`, muted text — NOT a colored side-stripe.

### Tech icons
- Vector via `react-icons` (Simple Icons `si*`) with `{ Icon, color }` map — NOT image files. Matches existing `TECH_ICONS` in `Work.tsx`.

### TechStack spheres (`src/components/TechStack.tsx`)
- Logos = square transparent `.webp` in `public/images/`, appended to `imageUrls` array. Brand-colored logo centered on transparent bg, ~256–512px, 7–20KB.

### Banned (AI tells) — reaffirmed for this project
- No `border-left/right` accent stripes >1px. No gradient text (`background-clip:text`). No decorative glassmorphism. No purple→blue gradients. No bounce/elastic easing. Motion = transform/opacity only.
